---
description: How to setup and run YATI-LMS
---
1. Ensure MongoDB is running on your system
2. Open two terminal tabs
3. In tab 1, navigate to yaticorp-lms-server and run `npm run dev`
4. In tab 2, navigate to yaticorp-lms-student and run `npm run dev`
5. Open your browser to the URLs provided by the dev servers.
