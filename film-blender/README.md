# The Stranger Who Changed Everything — Blender cartoon film

A 2 min 33 s, 16:9, 24 fps animated short with no dialogue, voice-over, subtitles or on-screen text. Everything
(characters, rigs, sets, acting, cameras) is generated by the Python scripts here in Blender 4.2 LTS (Eevee).

| File | What it does |
|---|---|
| `scripts/kit.py` | materials (sRGB colours), rounded primitives, tori, metaballs, bone parenting, fast F-curve baking |
| `scripts/chars.py` | Arjun, Ravi, the Interviewer: 15-bone armatures, every body part bound to a bone; faces with blinking lids, brows, shape-keyed mouth (smile / frown / open) |
| `scripts/anim.py` | the acting engine: paths (walk / run / slow / glide / cut), blended poses, expressions, head looks, breathing, blinks, props shown/hidden |
| `scripts/sets.py` | home (morning), bus stop in rain (geometry-node rain, wet road, puddles, auto-rickshaw, bus), office, evening street, photo insert, portrait studio |
| `scripts/build_film.py` | casts, acts and shoots the story (31 shots), fades, world light per scene → `stranger_film.blend` |
| `scripts/render_film.py` | `stills` (one per shot), `frames` (resumable PNG frames), `encode` (frames → MP4 in `output/`) |

```
B=/path/to/Blender.app/Contents/MacOS/Blender
$B -b --factory-startup --python scripts/build_film.py                          # build the .blend (~20 s)
$B -b stranger_film.blend --python scripts/render_film.py -- stills 50          # check shots
$B -b stranger_film.blend --python scripts/render_film.py -- frames 50          # 640x360 (100 = 1280x720)
$B -b --python scripts/render_film.py -- encode film.mp4                         # MP4
```

The first render in each Blender session spends ~15 min compiling shaders (Intel Mac, Metal); after that a frame takes
about 6–7 s at 640×360. Delete `renders/frames` before rendering at another size.

Scenes: 1 An important morning (0–20 s) · 2–4 The stranger, the decision (20–104 s) · 5–6 The office, the twist and the
handshake (104–138 s) · the walk home (138–153 s).
